# 企业微信接入

本项目接入的是企业微信官方**智能机器人 API 模式 / 长连接**，使用 `@wecom/aibot-node-sdk`。不需要公网回调服务。

## 接入步骤

1. 在企业微信中创建或配置智能机器人，开启「API 模式」，选择「长连接」。具体入口及可用权限以企业后台为准。
2. 取得该机器人的 **Bot ID** 和 **长连接 Secret**。它们不是企业 Corp ID、应用 Secret 或消息推送 Webhook。
3. 启动本项目，在「设置 → 企业微信智能机器人」填写并连接。稍后点「检查连接」，必须显示「已连接」才算认证成功。
4. 私聊机器人发送一条测试消息，或在机器人已加入的内部群里 **@机器人** 发送文字。本工具不自动回复。
5. 消息来源选择「企业微信消息」。首次可以不填关键词直接点击搜索，列出本机已收到消息的会话；选择后读取已接收消息。
6. 设置你的身份与职责，手动分类或预览后交给 Jev。加入待办、拖动、完成、保存与飞书一致。

收到新消息后点「刷新消息」，或在分类前读取最新缓存。不要把机器人静默不回复误认为未接收，以本工具的连接状态及收到条数为准。

## 读取范围

- 接收：与机器人私聊、群内 @机器人的消息。
- 不支持：个人账号所有聊天、未 @机器人的普通群消息、连接前的历史回补、会话存档。
- 接口没有提供可用群名/成员显示名时，显示平台会话 ID / 用户 ID。可按这些 ID 搜索；不能宣称已经搜索企业全部群。
- 文本、图文中的文字和企业微信已经返回的语音转写可分类；不下载图片、文件或音视频。图文附件会标注未读取。
- 当前没有企业微信原生消息定位链接，不伪造跳转地址。
- 时间显示为本机收到该消息的时间，非平台原始发送时间。

## 连接与存储

同一机器人只允许一个有效长连接。其他客户端接入同一个机器人可能使此工具掉线；状态会提示连接被替换。不要同时把一个机器人交给多个服务。

页面输入凭证仅在服务内存保存。希望重启后自动连接，可在忽略提交的 `.env` 中配置：

```dotenv
WECOM_BOT_ID=your_bot_id
WECOM_BOT_SECRET=your_long_connection_secret
```

接收消息缓存保存在 `.data/wecom-inbox.json`，文件权限仅当前用户可读写；总计最多保留最近 1,000 条，按机器人区分。不保存回调中的附件 URL、AES 密钥或机器人 Secret。此目录已被 Git 忽略。浏览器侧分类与待办仍保存在 localStorage。

默认接收不等于同意发送给 Jev；每次模型分类仍要求核对预览确认。请只接入有权处理的工作会话。

## 验证边界

实现已通过模拟 SDK 事件和 DOM 测试：认证状态、去重、私聊/群隔离、缓存重载、机器人切换和人工入队。真实企业微信登录、收到首条消息、真实 Jev 分类仍需使用者凭证完成端到端验收；不要把离线测试当作已完成真实接入。
